# WakeTone website

This repository contains the public static website for WakeTone, a Windows app by p2xstudio. The app source code is not in this repository.

The site uses plain HTML and CSS and can be published with GitHub Pages from the root of the `main` branch. The repository is https://github.com/doanthaiuyen8-ops/waketone; support requests can be filed at https://github.com/doanthaiuyen8-ops/waketone/issues. Replace the Store placeholder in `index.html` when the listing is available.
